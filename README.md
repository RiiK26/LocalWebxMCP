**LocalWeb x MCP** is a local web server built with Go (Golang).
modern UI for managing local files and a built-in **Model Context Protocol (MCP)** endpoint that allows AI
assistants (like Gemini Spark) to securely interact with your local environment.

## ✨ Key Features

*   **📂 File Management:** A responsive, dark-mode Web UI with drag-and-drop support for easy local file uploads.
*   **🤖 MCP Endpoint:** A dedicated `/mcp` route that handshakes with AI models, granting them specific tools to
    interact with your data.
    to analyze your local documents in real-time.

**To make the MCP server available to cloud-based AI models, you need to expose the local port `8080` to the internet.** This can be achieved using a secure SSH tunnel

## 🧰 Current MCP Tools Capability

The built-in MCP server equips the AI with Linux-like commands to manage and analyze your local storage:

*   **`list_files` (ls -la):** Lists all files in the storage along with metadata like file size and last modified date.
*   **`cat_file` (cat):** Reads and outputs the entire text content of a specified file.
*   **`find_files` (find):** Searches the storage directory for files matching a specific partial name.
*   **`grep_file` (grep):** Scans inside a specific file for a text pattern and returns the exact matching lines.
*   **`write_file` (touch/echo):** Creates a new file or overwrites an existing one with text generated by the AI.

## 🚀 Getting Started

### 1. Prerequisites
*   [Go](https://go.dev/dl/) (version 1.26 or higher) installed on your machine.
*   Git

### 2. Installation
Clone this repository to your local machine:
```bash
git clone https://github.com/ItsMe-RiiK/LocalWebxMCP.git
cd LocalWebxMCP
```

### 3. Run the Server
Execute the application directly from the root directory:
```bash
go run Backend/cmd/main.go
```
*The server will start instantly. It will automatically create a `Storage/` directory if it doesn't exist.*

### 4. Access the UI
Open your web browser and navigate to:
👉 **`http://localhost:8080`**

## 🤖 Connecting to an AI Client (MCP Setup)

To allow a cloud-based AI (like Gemini Spark) to communicate with your local MCP endpoint, you need to expose your local port `8080` to the internet using a secure SSH tunnel.

### Using localhost.run
Generate an SSH key (if you haven't already), and run:
```bash
ssh -R 80:127.0.0.1:8080 localhost.run #if u already register localhost and have the public key
or
ssh -R 80:localhost:8080 nokey@localhost.run
```

### Adding to the AI Client
Once you have your public URL (e.g., `https://your-tunnel-url.lhr.life`), append `/mcp` to it
